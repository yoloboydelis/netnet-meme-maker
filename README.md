# Netnet Meme Maker

Free, no-login meme generator for the Netnet Capital community ($NET · [@NetNetCap](https://x.com/NetNetCap)), starring Al Dunlap, the rock of the Netnet ecosystem.

- Drag-and-drop editor: templates, Impact-style captions, stickers, uploads, layers, undo, PNG download
- 50+ blank Al Dunlap scenes and 40+ captioned "remix" templates
- Free AI mode (Pollinations image API, no key) with Dunlap auto-added to every prompt
- Random bullish caption ideas, watermark toggle, share to X

Pure static site (HTML/JS, Fabric.js from CDN). Templates are stored as base64 text in `t/` and decoded in the browser. Memes only, not financial advice.
